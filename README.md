A make.fun bounty entry for "Famous Last Words at 1 Percent": a Node program that writes exactly one line — the funniest last words a phone says when its battery hits 1 percent — to `/output/entry.txt`. The phone spends its final percent on one petty act of revenge: it could have switched off the 6 a.m. alarm, and it chose not to.

## Run it

```sh
node main.ts
```
